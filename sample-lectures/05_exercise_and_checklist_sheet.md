# 2. 実習課題

## 課題 1：階乗の再帰実装と計算量

非負整数 $n$ に対して $n!$ を計算する関数を実装し、時間計算量と空間計算量を求めなさい。

```rust
fn factorial(n: u64) -> u64 {
    match n {
        0 | 1 => 1,
        _ => n * factorial(n - 1),
    }
}
```

## 課題 2：アルゴリズム比較表の記入

次の表の空欄を埋め、用途に応じた使い分けを説明しなさい。

| アルゴリズム | 最良計算量 | 平均計算量 | 最悪計算量 | 安定性 |
| :--- | :---: | :---: | :---: | :---: |
| 挿入ソート | $O(n)$ | $O(n^2)$ | $O(n^2)$ | 安定 |
| マージソート | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | 安定 |
| クイックソート | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | 不安定 |

# 3. 解答・解説（教員用／復習用）

> [!NOTE]
> 印刷時に問題ページと解答ページを分けたい場合は、`<!-- pagebreak -->` を挿入しておくと 2 ページ目以降に綺麗に分割されます。

1. **課題 1 の解答**:
   - 再帰呼び出しが $n$ 回発生するため、時間計算量は $O(n)$ です。
   - コールスタックを深さ $n$ 分消費するため、空間計算量も $O(n)$ となります。
2. **課題 2 のポイント**:
   - ほぼ整列済みのデータでは **挿入ソート** が高速に動作します。
   - 最悪計算量を確実に $O(n \log n)$ に抑えたい場合や安定性が必要な場合は **マージソート** を選びます。
